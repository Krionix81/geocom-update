GeocomDecoder 0.2.6 для Windows x64.

## Features

- В экспорт SUCOP добавлена возможность включать дату и время замеров; выбранная настройка сохраняется.

## Enhancements

- Руководство пользователя открывается из меню «Справка» и по F1 без внешних файлов PDF или CHM.
- Добавлен единый набор SVG-значков для панелей инструментов, настроек, графиков, таблиц и контекстных меню.
- Обновлена навигация по настройкам: компактные карточки, более понятные отступы и индикация фокуса при управлении с клавиатуры.
- Глянцевые индикаторы состояния заменены плоскими; уточнено отображение состояний пакетов WITS/WITSML.
- Удалены неиспользуемые ресурсы значков.

## Bug Fixes

- Исправлены русские переводы и отсутствовавшая подстановка параметра.
- Исправлены масштабирование значков индикаторов и обрезка подписей при высоком DPI и в узких панелях.
- Исправлены значки состояния соединения с наземным блоком.
- Исправлены регистрация 64-битных компонентов установщика и определение установленной версии при обновлении.
- Исправлено отображение русских описаний релизов в Advanced Installer Updater.
- Исправлена автоматическая замена предыдущих версий приложения при установке.
